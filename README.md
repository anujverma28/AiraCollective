# The Aira Collective — Website Workspace

## Open locally on Mac
1. Open this folder in VS Code.
2. Install the **Live Server** extension by Ritwick Dey if needed.
3. Open `index.html`.
4. Click **Go Live** in the bottom-right of VS Code.
5. Your browser will show the live site at a local address such as `http://127.0.0.1:5500/`.

## Files
- `index.html` — page structure/content
- `styles.css` — visual styling/layout
- `script.js` — interactions
- `assets/The Rustic Suite/` — property photos, logo and reel

Edit, save, and refresh/let Live Server update the browser.
